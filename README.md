# iPhone 18 Showcase

Интерактивный обзор актуальной линейки iPhone. В центре интерфейса находится интерактивная 3D-модель телефона: её можно вращать, менять модель и покрытие, исследовать отдельные детали и запускать автоматический обзор. Главная страница прокручивается: ниже интерактивной студии находится раздел о профиле, кнопках и инженерной конструкции. Повторного каталога моделей и повторного выбора цвета нет.

> 3D-визуализация является независимой интерпретацией. Размеры и масса iPhone Duo, iPhone 18 Pro, iPhone 18 Pro Max и iPhone Air взяты из технических спецификаций Apple. Для базового iPhone 18 официальные параметры ещё не объявлены, поэтому он явно помечен как концепт.

## Возможности

- пять моделей: iPhone Duo, iPhone 18 Pro, iPhone 18 Pro Max, iPhone Air и предварительный концепт базового iPhone 18;
- официальные цветовые семейства для Duo, Pro и Air; отдельная концептуальная палитра базовой модели;
- пересобранный корпус, широкая камера-платформа Pro, многослойная оптика, рамка, кнопки и динамики;
- раскрытие/складывание Duo, единый внутренний экран и отдельный внешний экран;
- вращение мышью и пальцем;
- декоративный домашний экран с нарисованными иконками; настоящая боковая 3D-кнопка включает и выключает экран, свайп вверх разблокирует устройство;
- интерактивные HTML-точки камер, дисплея, корпуса, кнопки и динамиков с проверкой перекрытия геометрией и кнопкой скрытия;
- автоматический обзор деталей и возврат в начальное положение;
- подсказки при первом посещении;
- адаптивная компоновка для компьютера, планшета и телефона;
- статичная облегчённая версия при отсутствии WebGL, малом объёме памяти или ошибке сцены;
- доступные подписи элементов управления и поддержка `prefers-reduced-motion`.

## Установка и локальный запуск

Понадобится Node.js 22 или новее и npm.

```bash
git clone https://github.com/USERNAME/iphone-18-showcase.git
cd iphone-18-showcase
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Сборка и проверка

```bash
npm run lint
npm run build
npm run start
```

Команда `npm run build` создаёт оптимизированную production-сборку. После неё `npm run start` запускает локальный production-сервер.

## Где менять содержимое

- Модели и их размеры: `data/models.ts`. Значения `width`, `height` и `depth` задаются в единицах сцены Three.js. Там же меняются диагональ, процессор, вес, число камер и флаг `foldable`.
- Цвета корпуса: `data/colors.ts`. `hex` отвечает за цвет, `metalness` — за металлический блеск, `roughness` — за матовость. Функция `colorsForModel` определяет палитру каждой модели.
- Описания деталей: `data/features.ts`. Каждая запись содержит заголовок, описание, три характеристики и ракурс `rotation`.
- Порядок автоматического обзора: массив `tourOrder` в `data/features.ts`.
- Геометрия корпуса и камер: `components/DeviceHardware.tsx`. Шарнир Duo и размещение деталей: `components/PhoneModel.tsx`.
- Экран блокировки, фон и иконки: `components/DeviceScreen.tsx`.
- Визуальная тема и адаптивность: `app/globals.css`.

## Как устроена 3D-сцена

`PhoneScene.tsx` создаёт React Three Fiber Canvas, камеру, студийное окружение из Lightformer, направленный свет, контактную тень и `OrbitControls`. Корпус построен в `DeviceHardware.tsx` из экструдированных скруглённых контуров с фасками. Широкий блок камер Pro, отдельная задняя вставка, линзы, рамки оптики, антенны, кнопки и отверстия динамиков — отдельные детали. Их форма меняется в зависимости от модели. Из локального `public/models/iphone-pro.glb` используется геометрия эмблемы; Draco-декодер также локальный.

Источник геометрии эмблемы — **Apple iPhone 15 Pro Max Black**, автор **polyman Studio**, лицензия **CC BY 4.0**. Это не официальная модель iPhone 18. Оригинал, источник файла и перечень изменений указаны в [ATTRIBUTION.md](public/models/ATTRIBUTION.md). Сохраняйте атрибуцию при публикации. GLB занимает около 887 КБ.

Материал корпуса получает цвет, металличность и шероховатость из `data/colors.ts`. При выборе детали корневая группа модели плавно поворачивается к сохранённому ракурсу. Пользовательское управление камерой остаётся доступным через `OrbitControls`.

Экран рисуется в HTML Canvas в двойном разрешении и передаётся в Three.js как `CanvasTexture`. Поэтому lock screen и домашний экран не требуют внешних изображений. Вертикальный жест на плоскости экрана меняет состояние текстуры, а интерактивная боковая кнопка включает и выключает дисплей. У Duo внутренняя текстура разделена между двумя половинами, внешний экран независимый; поворот группы вокруг шарнира складывает устройство. Геометрия, текстуры и клонированные ресурсы освобождаются при размонтировании.

Маркеры используют Drei Html с `occlude`: DOM-кнопки не разрезаются поверхностью корпуса, а целиком скрываются за ним. Карточка расположена в отдельной колонке, на мобильном — под сценой. Закрыть её можно кнопкой или Escape.

## Производительность

- Не повышайте `dpr` Canvas без необходимости: текущий предел `1.6` сохраняет чёткость и не перегружает мобильный GPU.
- Для новых деталей предпочитайте простую геометрию и повторное использование материалов.
- Не увеличивайте `shadow-mapSize` выше `1024` без проверки на реальных телефонах.
- Если появятся текстуры, используйте WebP/AVIF, разумное разрешение и предварительное сжатие.
- Тяжёлые постэффекты лучше подключать только для мощных устройств.
- Проверяйте Chrome DevTools Performance и FPS на мобильном устройстве, а не только на компьютере.

## Доступность

- Все основные кнопки имеют видимую подпись или `aria-label`.
- Выбранные варианты моделей и цветов сообщаются через `aria-pressed`.
- Карточка детали использует `aria-live`, поэтому её обновление доступно скринридеру.
- При `prefers-reduced-motion: reduce` декоративные анимации отключаются, ракурс меняется без плавного движения, а шаги обзора переключаются вручную.
- Детали доступны не только через 3D-точки, но и через обычные подписанные кнопки.
- Не удаляйте `focus-visible`-обводки и следите за контрастом при изменении палитры.

## Публикация через Vercel

1. Войдите на [vercel.com](https://vercel.com) через GitHub.
2. Нажмите **Add New → Project** и импортируйте репозиторий `iphone-18-showcase`.
3. Vercel автоматически определит Next.js. Build Command оставьте `next build`, Output Directory — без значения.
4. Нажмите **Deploy**. API-ключи и переменные окружения не нужны.
5. Каждый следующий push в `main` будет обновлять production-версию.

### Собственный домен без слова Vercel

Купите домен у любого регистратора отдельно. Затем откройте проект в Vercel: **Settings → Domains → Add Domain**, введите домен и добавьте у регистратора DNS-записи, которые покажет Vercel. Обычно для корневого домена используется A-запись, а для `www` — CNAME. После проверки DNS назначьте основной домен через **Set as Primary**. Тогда сайт будет открываться, например, по `iphone18.example`, а технический адрес `*.vercel.app` можно не использовать в публичных материалах.

Домен не входит в этот репозиторий, не покупается автоматически и не требует изменений кода.
